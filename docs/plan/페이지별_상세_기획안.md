## 💬 2. Chat 페이지 (`/chat`)

### 2.1 레이아웃 구조 (채팅 히스토리 포함)

```
┌──────────────────────────────────────────────────────────────────────┐
│ Header (공통)                                                         │
├──────────────────────────────────────────────────────────────────────┤
│                │                                 │                    │
│  [히스토리]    │     메시지 영역                 │  [승인 사이드패널] │
│  사이드바      │     (왼쪽 정렬)                 │  (조건부 표시)     │
│  280px        │                                 │  400px             │
│  (접을 수 있음)│                                 │                    │
│                │                                 │                    │
│                ├─────────────────────────────────┤                    │
│                │ [입력창]                  [전송] │                    │
└────────────────┴─────────────────────────────────┴────────────────────┘
```

**상태별 레이아웃:**
- **기본**: 히스토리(280px) + 메시지(나머지)
- **승인 대기**: 히스토리(280px) + 메시지(나머지) + 승인(400px)
- **히스토리 닫힘**: 메시지(전체)
- **모바일**: 히스토리는 오버레이 방식
